# Beitragsrichtlinien

Danke, dass du zu diesem Projekt beiträgst! So läuft es ab:

1. **Branch erstellen** – nie direkt auf `main` arbeiten, z. B. `feature/mein-thema`.
2. **Kleine, klare Commits** – eine Änderung pro Commit, mit verständlicher Nachricht.
3. **Pull Request öffnen** – beschreibe, *was* du geändert hast und *warum*.
4. **Checkliste abarbeiten** – ein Bot postet automatisch eine Checkliste in deinen PR.
   Hake alle Punkte ab, bevor gemergt wird.

## Wichtig

- Keine Passwörter, API-Keys, Tokens oder privaten Daten committen.
- Teste deine Änderungen lokal, bevor du den PR öffnest.
- Wenn sich das Verhalten ändert: README aktualisieren.
