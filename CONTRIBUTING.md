# Contributing Guide

Thanks for helping with this project! Here is how it works:

1. **Create a branch.** Never work directly on `main`. Example: `feature/my-topic`.
2. **Make small, clear commits.** One change per commit, with a short and clear message.
3. **Open a pull request.** Explain *what* you changed and *why*.
4. **Go through the checklist.** A bot posts a checklist on your PR automatically.
   Tick all points before the PR is merged.

## Important

- Never commit passwords, API keys, tokens or private data.
- Test your changes locally before you open a pull request.
- If something works differently now, update the README.
